🌿 Pulmio — Triagem Inteligente de Tuberculose (Simulado com IA)

Pulmio é um aplicativo web desenvolvido para realizar triagem inicial de sintomas e análise simulada de imagem utilizando modelos de IA (Random Forest e CNN).
O objetivo é demonstrar como um fluxo de pré-diagnóstico poderia funcionar em um ambiente real — mas sem uso de modelos reais, apenas simulação controlada, ideal para estudos, portfólio e disciplinas da faculdade.


📱 Funcionalidades
✅ 1. Triagem de Sintomas

O usuário seleciona sintomas como:
Febre persistente
Tosse por mais de 3 semanas
Catarro com sangue
Perda de peso
Falta de ar
Entre outros

✅ 2. Upload de Imagem

O usuário simula o envio de:
Raio-X
Tomografia
Ou qualquer imagem
(Não há IA real — apenas armazenamento local)

✅ 3. Análise Simulada (Random Forest + CNN)

O arquivo src/lib/mlSimulator.js retorna:
Valores falsos
Gerados automaticamente
Combinados 50% / 50%

✅ 4. Tela de Resultado

Mostra:
Probabilidade do modelo Random Forest
Probabilidade do modelo CNN
Probabilidade final
Data e ID da análise

🎨 Design e Responsividade

Todas as 4 telas foram adaptadas para:
Desktop
Tablets
Celulares
Com foco em:
Acessibilidade
Layout limpo
Uso de espaçamentos consistentes
Cartões com bordas suaves e sombras


📝 Aviso Importante

Este projeto é totalmente educacional.
Não deve ser utilizado para diagnóstico real.
Os valores de IA são aleatórios, apenas para simulação.
